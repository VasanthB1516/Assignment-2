# 🎬 Netflix Landing Page Clone

This project is a front-end clone of the Netflix India landing page built using pure HTML5 and CSS3.

It replicates the visual layout and structure of the official Netflix homepage, including the hero section, trending content, features section, FAQ layout, and footer.

---

## 🚀 Features

- Hero section with background image overlay
- Navigation header with language selector and sign-in button
- Email subscription input section
- Trending movies grid using CSS Grid
- Feature cards with gradient backgrounds
- FAQ section layout
- Footer with multiple link columns
- Clean UI inspired by Netflix India

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Font Awesome Icons
